# Product Guide

## Standard Plan
The Standard plan is designed for small teams. It includes:
- Up to 5 user seats
- 10 GB data storage
- Email support (48-hour response SLA)
- Access to the web dashboard
- Basic reporting and analytics
- 99.5% uptime SLA

## Professional Plan
The Professional plan is ideal for growing businesses:
- Up to 25 user seats
- 100 GB data storage
- Priority email and chat support (8-hour response SLA)
- Advanced analytics and custom reports
- API access with 10,000 calls/month
- SSO integration support
- 99.9% uptime SLA

## Enterprise Plan
The Enterprise plan provides full-scale capabilities:
- Unlimited user seats
- Unlimited storage
- Dedicated customer success manager
- 24/7 phone and chat support (1-hour response SLA)
- Unlimited API access
- Custom integrations and white-labelling
- Advanced audit logging
- 99.99% uptime SLA with financial penalties for breaches

## Plan Upgrades and Downgrades
Upgrades take effect immediately with prorated billing.
Downgrades take effect at the next billing cycle.
Downgrading may result in data loss if usage exceeds the new plan limits.

## How-Tos

### How to add a user
1. Navigate to Settings → Team Members.
2. Click "Invite User" and enter their email address.
3. Select the appropriate role (Admin, Editor, Viewer).
4. Click Send Invitation.

### How to export data
1. Go to Settings → Data Management.
2. Click "Export Data" and choose the format (CSV, JSON, Excel).
3. Select the date range.
4. Click Export — an email with the download link is sent within 15 minutes.

### How to reset a password
Users can reset their own password via the "Forgot Password" link on the login page.
Admins can trigger a password reset from Settings → Team Members → select user → Reset Password.
